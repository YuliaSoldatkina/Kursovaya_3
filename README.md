# Проект по базам данных вакансий

Проект получает данные о компаниях и вакансиях с hh.ru, сохраняет их в PostgreSQL и предоставляет SQL-запросы для анализа вакансий.

## Возможности

- создание базы данных и таблиц PostgreSQL;
- загрузка данных из API hh.ru;
- загрузка резервных данных из JSON-файла;
- сохранение компаний и вакансий;
- поиск вакансий по ключевому слову;
- расчёт средней зарплаты;
- поиск вакансий с зарплатой выше средней;
- получение количества вакансий по компаниям.

## Установка

```bash
poetry install
```

Создайте файл `.env` в корне проекта:

```env
DB_NAME=hh_project
DB_USER=postgres
DB_PASSWORD=ваш_пароль
DB_HOST=127.0.0.1
DB_PORT=5432
```

## Запуск

```bash
poetry run python -m src.main
```

## Источник данных

При доступности API используется hh.ru. Если API возвращает ошибку доступа, проект использует резервный файл:

```text
data/hh_vacancies.json
```

## Структура

- `src/database.py` — создание базы и таблиц;
- `src/hh_api.py` — работа с API;
- `src/file_manager.py` — чтение JSON;
- `src/vacancy.py` — загрузка компаний и вакансий;
- `src/db_manager.py` — запросы к базе;
- `src/main.py` — точка входа.
